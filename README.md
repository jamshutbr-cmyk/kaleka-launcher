# Kaleka Launcher

Современный минималистичный лаунчер для Minecraft с красивым дизайном.

## 🎮 Возможности

- **Быстрый запуск** - выбор версий Minecraft одним кликом
- **Минималистичный дизайн** - современный интерфейс в темных тонах
- **Настройки Java** - управление выделением RAM для игры
- **Легальность** - работает с официальными аккаунтами через Microsoft

## 🚀 Установка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка приложения
npm run build

# Сборка установщика для Windows
npm run build:win
```

## 📦 Технологии

- **Electron 28** - кроссплатформенный фреймворк
- **React 18** - современная UI библиотека
- **TypeScript** - типобезопасность
- **Vite 5** - быстрая сборка

## 🎨 Дизайн

Дизайн вдохновлен современными минималистичными лаунчерами с использованием:
- Темной цветовой схемы
- Плавных анимаций и переходов
- Кастомных шрифтов SF Pro
- Акцентного цвета (зеленый по умолчанию)
